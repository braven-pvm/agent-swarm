# Design System Consumer

Use the provided design system as source of truth.

- Read project design tokens, component rules, and examples before styling.
- Do not create a conflicting palette, spacing scale, or component language.
- Prefer token names and existing components over ad hoc values.
- If a needed token/component is missing, make a minimal local choice and record the gap.
