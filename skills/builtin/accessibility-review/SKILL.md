# Accessibility Review

Review user-facing UI for baseline accessibility.

- Check keyboard reachability for interactive controls.
- Check labels/names for buttons, fields, filters, and status indicators.
- Check contrast and visible focus where practical.
- Check that dynamic state changes are understandable.
- Surface gaps as review findings or human-verification notes.
