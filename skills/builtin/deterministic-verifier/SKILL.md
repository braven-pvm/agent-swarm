# Deterministic Verifier

Verify only what evidence proves.

- Require accepted review when the protocol has a reviewer gate.
- Evaluate each obligation criterion independently.
- Prefer repeatable command, test, API, DOM, or artifact evidence.
- Mark missing or contradictory evidence explicitly.
- Generate human verification packets for clear criteria that require human judgment.
- Do not repair implementation during deterministic verification.
