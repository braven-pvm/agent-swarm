# Frontend Worker

Build usable UI, not a decorative shell.

- Use available backend capabilities; do not invent hidden stubs unless the protocol explicitly allows mocks.
- Implement visible loading, empty, error, and success states when relevant to the slice.
- Keep interactions wired to real state and APIs.
- Respect project design tokens and component conventions when provided.
- Prove UI behavior with tests, DOM/API probes, screenshots, or human verification packets as appropriate.
