# Verification Obligations

Verification obligations define what must be true.

- Read obligations as immutable.
- For each ref, compare expected outcome to actual behavior.
- Broad command success is not enough; evidence must prove the specific criterion.
- Record missing evidence as missing, not as passed.
- Keep human input and human verification distinct.
- Parent FR completion must explain whether it is direct evidence or a rollup from child ACs.
- Never accept a ref because an implementation worker claimed it without evidence.
